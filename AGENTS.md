# Sirius Cloud — instruções do repositório

- Mantém a experiência em português de Angola (`pt-AO`) e preserva a identidade dark azul/violeta.
- Não apresentes dados demonstrativos como recursos ou operações reais. Indica claramente quando uma acção é simulada.
- Nunca adiciona credenciais, tokens ou segredos ao repositório.
- Não acedas directamente à base de dados interna do Coolify; a integração deve usar API pública verificada.
- Não executa operações externas com custos, alterações de DNS ou deployments de produção sem autorização explícita.
- Actualiza `IMPLEMENTATION_PLAN.md`, `docs/product/FEATURE_MATRIX.md` e `CHANGELOG.md` quando o estado do produto mudar.
- Antes de declarar uma integração concluída, verifica a sua capacidade e documenta limitações.
